# GuardianLens User Study Session Script, Draft

**Do not execute until O-3 is closed and Gate D has passed.**

1. Confirm the consent record and assign the participant code and counterbalancing group.
2. Explain the task without teaching fraud cues: judge each listing as fraudulent or legitimate using the information shown.
3. Run practice items that are outside the held-out test set.
4. Present the two matched sets of eight listings in the counterbalanced order. Each set contains four fraudulent and four legitimate hold-out listings with independent evidence.
5. For unaided trials, record judgement, decision time, and confidence without showing GuardianLens.
6. For assisted trials, show the fixed prototype result, record judgement, decision time, confidence, and whether the participant changed their answer.
7. Administer the post-session usefulness, clarity, and trust-calibration questionnaire.
8. Check the session record for missing fields before dismissing the participant. Do not alter answers.

Deviation rule: log any interruption, misunderstood instruction, technical failure, or exposure to the other condition. Never silently repair a trial row.
